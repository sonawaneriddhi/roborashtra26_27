Steps to Run

Install Node.js 18.17 or newer from nodejs.org.

Open CMD in the project folder:


Install dependencies using the Python installer:
python install_dependencies.py
Or directly with npm:
npm ci

Start the development server:
npm run dev
Open the URL shown in the terminal, usually:

Production mode
npm run build
npm start

The requirements.txt is for documentation only. Do not use pip install -r requirements.txt; this is a Node.js project.
